# 🤖 ESP32 สถานีคัดกล่อง (จำลองบน Wokwi)

ไม่ต้องมีบอร์ดจริง — ESP32 รันในเบราว์เซอร์ที่ [wokwi.com](https://wokwi.com) รับผล PASS/FAIL จาก bridge ผ่าน MQTT แล้วคัดกล่องเสียลงลังให้เห็น

จอ OLED แสดงภาพสายพานแบบมองจากด้านบน กล่องวิ่งจากกล้องไปตามสายพาน กล่องดีวิ่งออกปลายสาย (OUT) กล่องเสียวิ่งไปถึงลูกสูบของตัวเอง ลูกสูบดันกล่องตกลงลังแยก **DENT** / **TEAR** ตัวเลขในลังเพิ่มขึ้น และไฟประจำลังติด

```
 กล้อง ▼        ลูกสูบ1      ลูกสูบ2
 ┌──[กล่อง]─────────┬───────────┬──────────►  OUT (ส่งออก)
 └──────────────────┼───────────┼───────────
              ┌─────▼─────┐┌────▼──────┐
              │  DENT  3  ││  TEAR  2  │
              └───────────┘└───────────┘
```

| อุปกรณ์ | ขา | ทำอะไร |
|---|---|---|
| จอ OLED 128x64 | SDA 21 / SCL 22 | ภาพเคลื่อนไหว สายพาน → ลูกสูบดัน → กล่องตกลง |
| Servo ลูกสูบ DENT (แขนสีน้ำเงิน) | GPIO 18 | กล่องบุบมาถึง → หมุน 90° ดันออก แล้วกลับ |
| Servo ลูกสูบ TEAR (แขนสีส้ม) | GPIO 13 | กล่องฉีกมาถึง → หมุน 90° ดันออก แล้วกลับ |
| ไฟ DENT BIN (น้ำเงิน) | GPIO 32 | ติดตอนกล่องตกลงลัง DENT |
| ไฟ TEAR BIN (ส้ม) | GPIO 33 | ติดตอนกล่องตกลงลัง TEAR |
| ไฟเขียว (RUN) | GPIO 25 | สายพานทำงาน · กะพริบเมื่อกล่อง PASS |
| ไฟเหลือง (WAIT) | GPIO 26 | กะพริบ = กำลังต่อ WiFi/MQTT · ติดค้าง = bridge ปิดอยู่ |
| ไฟแดง (REJECT) | GPIO 27 | เจอกล่องเสีย ติด 1.5 วินาที |
| Buzzer | GPIO 19 | ปี๊บสั้น ๆ ตอนเจอกล่องเสีย |
| จอ LCD 16x2 (I2C) | SDA 21 / SCL 22 | ผลล่าสุด + ตัวนับ P(ผ่าน) D(บุบ) T(ฉีก) OUT(ส่งออก) |
| ปุ่ม TEST FAIL | GPIO 4 | กดทดสอบได้โดยไม่ต้องมีเน็ต (สลับ dent / tear) |

> Wokwi ไม่มีลูกสูบเชิงเส้น (linear actuator) จึงใช้ servo หมุนแทนการดัน ส่วนภาพการดันลูกสูบจริงดูได้บน OLED
> ถ้าทำบอร์ดจริง ใช้ servo ตัวเดิม หรือเปลี่ยนเป็นรีเลย์สั่งกระบอกลม/โซลินอยด์ที่ขาเดียวกันได้
> ชื่อคลาสที่มีคำว่า `tear` หรือ `torn` ไปลัง TEAR ส่วนกล่องเสียแบบอื่นทั้งหมดไปลัง DENT

## ทำไมต้องมี relay
Wokwi รัน ESP32 บนคลาวด์ จึงมองไม่เห็น broker บนโน้ตบุ๊ก (`127.0.0.1`)
`npm run relay` จะรับผลจาก bridge แล้วส่งต่อไป public broker (`broker.hivemq.com`) ให้ ESP32 อ่านได้

```
CiRA → Mosquitto → bridge → spdi/line1/counted → relay → broker.hivemq.com → ESP32 (Wokwi)
                                                                     ↑ ack กลับมาแสดงใน relay
```
ส่งไปแค่ `{"r":"FAIL","c":"dent","n":12}` ไม่มีภาพ ไม่มีข้อมูลฐานข้อมูล · topic มีรหัสสุ่มเพื่อไม่ให้ชนกับคนอื่น

## วิธีใช้ (ครั้งแรก)
1. รัน relay แบบทดสอบ (ไม่ต้องเปิด broker/CiRA):
   ```bash
   npm run relay:test
   ```
   ครั้งแรกจะสร้าง `RELAY_TOPIC=spdi-xxxxxxxx/line1` ลงใน `bridge/.env` ให้เอง และพิมพ์ออกมาให้เห็น
2. เปิด https://wokwi.com/projects/new/esp32
3. แท็บ **sketch.ino** → ลบของเดิม วางโค้ดจาก [wokwi/sketch.ino](wokwi/sketch.ino)
   แก้บรรทัด `#define TOPIC_BASE "spdi-xxxxxxxx/line1"` ให้ตรงกับ `RELAY_TOPIC` ในข้อ 1
4. แท็บ **diagram.json** → ลบของเดิม วางจาก [wokwi/diagram.json](wokwi/diagram.json)
5. แท็บ **Library Manager** → กด **+** เพิ่ม 5 ตัว: `PubSubClient`, `ESP32Servo`, `LiquidCrystal I2C`, `Adafruit GFX Library`, `Adafruit SSD1306` (ดู [wokwi/libraries.txt](wokwi/libraries.txt))
6. กด ▶ (รอ compile ครั้งแรกนานหน่อย) → ทุก 3 วินาทีจะมีกล่องเข้ามาบนจอ OLED กล่องดีวิ่งออกปลายสาย กล่องเสียโดนลูกสูบดันลงลัง ไฟประจำลังติด
7. กด **SAVE** (ล็อกอิน Wokwi ฟรี) จะได้ลิงก์ไว้เปิดตอนเดโม

## ใช้กับระบบจริง
**ง่ายสุด:** ดับเบิลคลิก `runall.bat` ที่โฟลเดอร์โปรเจกต์ — เปิดทุกอย่างรวม relay ให้เลย แล้วกด ▶ ใน Wokwi (ตัวจำลองส่งทั้งกล่อง dent และ tear จึงเห็นลูกสูบทั้ง 2 ตัวทำงาน)

หรือเปิดเอง:
เปิดตามปกติ (`3-DEMO-CIRA.bat` หรือ `npm run demo:cira`) แล้วเปิดอีกหน้าต่าง:
```bash
npm run relay
```
หรือใช้กับตัวจำลอง: `npm run demo:sim` + `npm run relay`

## ใช้กับบอร์ดจริงภายหลัง
โค้ดเดียวกันใช้ได้เลย แก้ `WIFI_SSID` / `WIFI_PASS` เป็น WiFi จริง แล้ว upload ด้วย Arduino IDE (ติดตั้ง 5 library เดียวกัน)

## แก้ปัญหา
| อาการ | ทางแก้ |
|---|---|
| ไฟเหลืองกะพริบไม่หยุด | ESP32 ต่อ MQTT ไม่ได้ ดู Serial Monitor (`MQTT failed, rc=...`) ลองกด ▶ ใหม่ |
| ไฟเหลืองติดค้าง จอขึ้น `Bridge offline` | relay ไม่ได้รัน หรือ `TOPIC_BASE` ไม่ตรงกับ `RELAY_TOPIC` |
| relay ไม่ขึ้น `🤖 ESP32: ...` | ESP32 ยังไม่ได้รัน / topic ไม่ตรง |
| Simulation ช้ามาก (ความเร็วมุมขวาบนต่ำกว่า 30%) | ปิดแท็บอื่นที่หนัก ๆ · ช่วงต่อ WiFi ตอนเริ่มจะช้าเป็นปกติ รอสักครู่ |
| `npm run relay` ขึ้น `ECONNREFUSED` | broker ในเครื่องยังไม่รัน → ใช้ `npm run relay:test` หรือเปิด broker ก่อน |
