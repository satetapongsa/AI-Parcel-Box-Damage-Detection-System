# auto_label.py — ตีกรอบกล่องอัตโนมัติ แล้วเซฟเป็น `.gt` ของ CiRA CORE

โปรแกรมหากล่องพัสดุในรูปทุกรูปของโฟลเดอร์ แล้วสร้างไฟล์ `<ชื่อรูป>.gt` วางไว้ข้างรูปในโฟลเดอร์เดียวกัน
จากนั้นเปิดโฟลเดอร์นั้นใน **CiRA DeepTrain → Labeling** เพื่อตรวจ/แก้กรอบ แล้ว Generate + Train ได้เลย

## ติดตั้ง (ครั้งเดียว)
```bash
py -m pip install opencv-python numpy
```
```bash
py -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```
```bash
py -m pip install ultralytics
```
(ใช้คำสั่ง `py` บน Windows ถ้าพิมพ์ `python` แล้วเด้งไป Microsoft Store)

## ใช้งาน
```bash
py tools/auto_label/auto_label.py "C:/Users/PC/Desktop/box_good/dataset_frames" --preview
```
- ได้ไฟล์ `box_0000.gt`, `box_0001.gt`, ... ข้างรูปแต่ละรูป
- `--preview` = เซฟรูปที่วาดกรอบแล้วไว้ใน `_preview/` ไว้ดูว่าตีถูกไหม
- รูปที่**มี `.gt` อยู่แล้วจะไม่ถูกเขียนทับ** (กันงานที่ตีมือหาย) ถ้าต้องการทับให้ใส่ `--overwrite`
- ครั้งแรกจะโหลดโมเดล AI (~340 MB) ใช้เวลาประมาณ 0.3 วินาที/รูป บน CPU

## วิธีตรวจจับ (`--method`)
| method | ใช้เมื่อ | หมายเหตุ |
|---|---|---|
| `ai` (ค่าเริ่มต้นเมื่อติดตั้ง ultralytics) | ทุกกรณี | YOLO-World: AI ที่บอกได้เลยว่าให้หา "cardboard box" ไม่ต้องเทรน **แม่นที่สุด** |
| `bg` | เฟรมจากวิดีโอที่กล้องนิ่ง | ลบพื้นหลัง (สายพานว่าง) จับได้ทุกสีกล่อง, ไม่ต้องติดตั้ง AI |
| `color` | รูปเดี่ยว ๆ | จับจากสีน้ำตาลกล่องกระดาษ |
| `yolo` | มีโมเดลที่เทรนจาก CiRA แล้ว | ใช้ `test.cfg` + `train.weights` + `obj.names` ของ CiRA มาตีกรอบให้รอบถัดไป |

## ตัวเลือกที่ใช้บ่อย
| ตัวเลือก | ทำอะไร |
|---|---|
| `--label box_good` | ชื่อ class ที่จะใส่ (ค่าเริ่มต้น `box_good`) |
| `--min-area 0.05` | เอาเฉพาะกล่องใหญ่ (≥5% ของรูป) ตัดกล่องเล็ก ๆ ด้านหลังออก |
| `--roi 0,0.3,1,0.6` | เอาเฉพาะกล่องที่อยู่ในกรอบ x,y,w,h (0–1) เช่น เฉพาะแถบสายพาน |
| `--prompt "cardboard box" "parcel"` | ai: เปลี่ยนคำที่ให้ AI หา |
| `--ai-conf 0.3` | ai: เพิ่มเพื่อลดกรอบมั่ว / ลดเพื่อจับให้ได้มากขึ้น |
| `--imgsz 960` | ai: จับกล่องเล็ก ๆ ได้ดีขึ้น (ช้าลง) |
| `--dry-run` | ลองดูเฉย ๆ ไม่เขียนไฟล์ |
| `--eval FOLDER/_BACKUP.gt` | วัดความแม่น เทียบกับกรอบที่ตีมือไว้ |
| `--convert-text` | แปลงไฟล์ `.gt` แบบข้อความ (`box_good 662 364 552 443`) ให้เป็นรูปแบบ JSON ของ CiRA |

## ผลทดสอบ (เฟรมจาก `boxdetection.mp4`)
- เทียบกับ 11 รูปที่ตีมือไว้: **เจอกล่องครบทุกใบ (recall 100%)**, กรอบตรงกับที่ตีมือเฉลี่ย **IoU 0.86**
- AI เจอกล่องแถวหลังที่ไม่ได้ตีมือไว้ด้วย (นับเป็น "เกิน" ในตัววัด แต่เป็นกล่องจริง) ถ้าไม่อยากได้ใช้ `--min-area 0.05`
- กล่องที่เบลอมาก ๆ ใกล้กล้องอาจหลุด ต้องตีเพิ่มเองใน CiRA

## รูปแบบไฟล์ `.gt` ของ CiRA (JSON)
```json
[
  {
    "filename": "box_0000.jpg",
    "obj_array": [
      { "bbox": "698,372,483,430", "center": "940,587", "color": "255,0,255",
        "label": "box_good", "label_index": 0, "landmark": "", "landmark_len": 0 }
    ]
  }
]
```
`bbox` = x,y (มุมซ้ายบน), กว้าง, สูง เป็น pixel ของรูปจริง

⚠️ ไฟล์ `.gt` ที่ `cira_labeler.py` เขียน (`box_good 662 364 552 443`) **ไม่ใช่รูปแบบนี้** CiRA อาจอ่านไม่ได้ ให้รัน `--convert-text` ก่อนเอาไปเทรน

## ข้อควรรู้
- โปรแกรมตีกรอบเป็น `box_good` ทั้งหมด กล่องที่เสีย (`dent`, `tear`) ต้องเปลี่ยน class เองใน CiRA
- AI ช่วยประหยัดเวลา แต่ควรเปิดดูทุกรูปใน CiRA ก่อนเทรน กรอบผิดทำให้โมเดลเพี้ยน
