# วัดขนาดกล่อง (กว้าง × ยาว × สูง) จาก CiRA CORE

## สรุปสั้น

**ไม่ต้องเพิ่มโค้ดใน CiRA CORE** node JavaScript (`cira/cira_javascript_node.js`) ส่งกรอบของทุกกล่องมาอยู่แล้ว
(`x, y, w, h`) Bridge เอากรอบนี้มาเฉลี่ยทุกเฟรมที่เห็นกล่อง แล้วแปลงเป็นขนาดเอง

```
CiRA DeepDetect -> JavaScript node -> {objects:[{name, conf, x, y, w, h}]} -> MQTT -> Bridge -> size {lengthCm, widthCm, heightCm}
```

## ทำไมได้แค่ 2 ด้าน

CiRA ตรวจจับในภาพ 2 มิติจากกล้องตัวเดียว จึงเห็นได้แค่ 2 ด้านของกล่อง

| ตั้งกล้อง | `CAMERA_VIEW` | ได้ขนาด | ด้านที่ไม่เห็น |
|---|---|---|---|
| มองลงจากด้านบน | `top` | ยาว (ตามสายพาน) × กว้าง | สูง |
| มองจากด้านข้าง | `side` | ยาว × สูง | กว้าง |

ด้านที่ไม่เห็นใส่เป็นค่าคงที่ได้ใน `BOX_FIXED_DIM_CM` (เช่นกล่องทุกใบสูง 20 cm) ถ้าเว้นไว้จะแสดงเป็น `?`

## ตั้งค่าให้เป็นหน่วย cm (ทำครั้งเดียว)

1. ตั้งกล้องให้ตั้งฉากกับสายพาน และล็อกไม่ให้ขยับ (ขยับหรือซูมเมื่อไรต้องวัดใหม่)
2. วางไม้บรรทัดหรือตลับเมตรบนสายพาน แล้วอ่านจากภาพใน CiRA ว่าทั้งภาพกว้างกี่ cm (ซ้ายไปขวา) และสูงกี่ cm (บนลงล่าง)
3. ใส่ค่าใน Control Center → **Bridge settings** แล้วกด **Save & restart bridge**
   - `CAMERA_VIEW` = `top` หรือ `side`
   - `FRAME_WIDTH_CM` = ความกว้างของภาพเป็น cm
   - `FRAME_HEIGHT_CM` = ความสูงของภาพเป็น cm
   - `BOX_FIXED_DIM_CM` = ขนาดด้านที่กล้องไม่เห็น (0 = ไม่รู้)

ถ้ายังไม่ได้ตั้ง ระบบจะแสดงขนาดเป็น % ของภาพ (เช่น `32%×40% of frame`) และกล่องในภาพ 3D จะเล็กหรือใหญ่ตามสัดส่วนนั้น

## ความแม่นยำ

- ขนาดมาจากกรอบที่โมเดลวาด กรอบหลวมหรือแน่นเกินไปขนาดก็คลาดตาม (เทรนให้กรอบพอดีขอบกล่อง)
- กล่องที่อยู่ใกล้หรือไกลกล้องกว่าระนาบสายพาน (กล่องสูงมาก) ด้านบนจะดูใหญ่กว่าจริงเล็กน้อย ถ้ากล้องอยู่สูงคลาดเคลื่อนน้อยลง
- เลนส์มุมกว้างบิดภาพที่ขอบ วางกล่องตรงกลางภาพจะแม่นที่สุด

## ถ้าต้องการครบ 3 ด้านจริง

ต้องเพิ่มเซนเซอร์อีกตัว เลือกได้ 2 ทาง

1. **กล้องตัวที่ 2 มองด้านข้าง** ทำ flow ใน CiRA อีกชุดที่ใช้ node JavaScript เดียวกัน แต่ส่งไป topic ของอีกสาย
2. **เซนเซอร์วัดระยะ (เช่น HC-SR04 หรือ VL53L0X) บน ESP32** ติดเหนือสายพาน ความสูงกล่อง = ระยะติดตั้ง − ระยะที่วัดได้ แล้วส่งค่าขึ้น MQTT ให้ Bridge รวมกับผลของ CiRA

ทั้งสองทางต้องเพิ่มโค้ดใน Bridge ให้จับคู่ค่าของกล่องใบเดียวกัน
