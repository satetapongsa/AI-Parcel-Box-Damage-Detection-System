SPDI Bridge

Tracks boxes, decides PASS / FAIL

  • video: counted at virtual line x=0.5
  • image: one picture = one box
  • FAIL if ≥ 30% of frames damaged

Class mapping

bridge/.env · case-insensitive

  • PASS ← GOOD_CLASSES: box_good, box, good, good_box, o
  • FAIL ← DAMAGED_CLASSES: dent, tear, x, damage, damaged, defect …
  • any other name → skipped, not stored
